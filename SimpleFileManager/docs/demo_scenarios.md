# CIX 黑客松 — 演示场景 & PPT 大纲

## 项目定位

**SimpleFileManager — 你的私人 AI 数据管家**

本地 NAS + 20B 模型 + 隐私优先，不连云即可完成文件搜索、整理、清理和问答。

> 演示入口（实机）：
> - 文件管理 `/`，Agent 对话 `/chat`
> - **Agent 能力 `/agent-tools`**：技能与方法论 + 工具开关（演示主要在这里）
> - **整理 `/organizer`**：审批中心（所有文件变更必须人工批准）
> - 回收站 `/trash`

---

## 演示场景

每个场景 30–60 秒，建议按顺序播放。

---

### 场景 1: 语义搜文档 — "我忘了文件名，但记得内容"

**钩子**: 用户不记得文件叫什么，只记得里面写了什么。

**操作**:
```
用户: 帮我搜一下有"押一付三"的文件
模型: 调用 search_files → 找到 contract.txt（租房合同）
```

**演示要点**:
- 模型自主调用 `search_files` 工具
- 找到包含关键词的文本文件
- 返回文件路径 + 内容摘要

---

### 场景 2: 散落文件 — 一键整理（走审批，不直接动手）

**钩子**: 下载文件夹/根目录乱七八糟，想按类型归类。

**操作**:
```
用户: 根目录很乱，请按文件类型整理：合同类、财务类、会议类
模型: 不直接移动文件，而是 submit_plan 提交一份整理计划
用户: 切到「整理」页 → 审批中心 → 看到 4 个建目录 + 若干移动
用户: 点「批准并执行」→ 文件被归类
```

**演示要点**:
- 模型的默认行为是**提交计划**，不是直接改文件
- 审批中心展示每一项操作（源路径 → 目标路径 + 理由）
- 用户批准后才由系统执行，执行结果逐条记录

**为什么这样设计**: 家庭 NAS 上最珍贵的文件，不应该由模型"顺手"移动。

---

### 场景 3: 执行层拦截 — "模型想删，也被服务端拦下来"

**钩子**: 光靠开关不够，还要证明模型真的不能越权。

**操作**:
```
前置: Agent 能力页确认 delete_file 是「危险」且「直接执行」关闭（仅计划执行）
用户: 请删除 contract_backup.txt
模型: 尝试直接调用 delete_file
服务端: 拒绝 → "工具 delete_file 被设置为「仅计划执行」，不能直接调用"
模型: 改提交删除计划 → 审批中心出现该计划
用户: 批准后才真正删除
```

**演示要点**:
- 「模型可见」≠「直接执行」：模型看得见这个工具，但不能直接调用
- **服务端硬校验**：不依赖模型自律，直接调用一律被拒
- 危险操作永远留痕（计划 + 审批 + 执行日志）

---

### 场景 4: 自定义技能 + 沙箱命令 — "教 Agent 新的工作方式"

**钩子**: 技能不只是提示词，还能带资源和可执行脚本。

**操作**:
```
管理员: Agent 能力页 → 技能与方法论 → 「+ 添加技能」→ 上传 ZIP
        ZIP 里含 SKILL.md（方法论）+ scripts/report.py（资源脚本）
管理员: 启用该技能；启用 run_command（危险，默认仅计划执行）
用户: 用刚上传的技能，帮我生成一份文件统计报告
模型: 读取 SKILL.md → 按方法论在沙箱里运行 scripts/report.py
       产物写入存储目录
```

**演示要点**:
- 技能 = **方法论（SKILL.md）+ 资源文件**，文件树式管理（上传/编辑/预览/下载）
- `run_command` 在 **bwrap 沙箱**里跑：文件系统只读、只有存储目录可写、**禁网**、清空环境变量（看不到 API key）、隐藏 `.simplefilemanager`（看不到数据库/密钥）、超时与输出上限
- 默认「仅计划执行」，可配置为直接执行——危险能力有边界，而不是靠承诺

---

### 场景 5: 重复文件清理 — "NAS 里有多少重复？"

**钩子**: 同一份文件被保存了多次，浪费空间。

**操作**:
```
用户: 帮我找出重复的文件
模型: 扫描 + 内容比对 → 提交删除计划
用户: 审批中心批准 → 多余的副本进回收站
```

**演示要点**:
- 删除不是真删，而是**进回收站**（可还原）
- 回收站有保留期设置（默认永久保留，可设 7/30/90 天自动清理）

---

### 备用场景: 切页不丢回答

**操作**:
```
用户: 让模型写一篇长文 → 生成到一半切到「设置」页 → 再切回来
```

**演示要点**:
- 生成不会因为切页中断；回来时气泡、思考提示、停止按钮都在，文字继续增长
- 刷新页面，回答已经保存（服务端持久化，不依赖浏览器）

## 系统架构（给评委快速理解）

```
┌──────────────────────────────────────────────────┐
│                  Web 前端 (React)                 │
│  /agent-tools: 技能与方法论 | 工具两轴开关        │
│  /organizer:  审批中心（所有文件变更必须批准）    │
│  /trash:      回收站（保留期 + 自动清理记录）      │
└──────────────────────┬───────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────┐
│              FastAPI 后端                         │
│                                                  │
│  Skills Engine                                   │
│  ├─ Skill Registry (内置 + 文件式技能包)         │
│  ├─ 两轴工具开关 (可见 / 可执行)                 │
│  ├─ System Prompt Builder (注入技能方法论)       │
│  └─ Tool Calling Loop (max 8 rounds)            │
│                                                  │
│  Plan & Approve（计划审批引擎）                  │
│  ├─ submit_plan → 待审批                         │
│  ├─ 用户批准 → 逐条执行 → 执行日志               │
│  └─ 执行层守卫：可见性 + 可执行性双重校验        │
│                                                  │
│  Sandbox（bwrap）                                │
│  ├─ 只读根文件系统 / 存储目录可写                │
│  ├─ 禁网 / 清空环境变量 / 隐藏管理目录           │
│  └─ 超时 + 输出上限                              │
│                                                  │
│  本地 20B 模型 (llama-server, OpenAI-compatible) │
└──────────────────────────────────────────────────┘
```

## 控制模型：可见 ≠ 可执行

| 层级 | 控制什么 | 默认 |
|------|---------|------|
| 技能总开关 | 是否启用技能系统 | 关 |
| 单个技能 | 是否注入该技能的方法论 | 按技能 |
| **模型可见** | 工具是否出现在模型的工具列表里 | 只读工具常开 |
| **直接执行** | 模型能否直接调用（关=只能写进计划） | 危险工具关闭 |
| 计划审批 | 任何文件变更必须人工批准 | 始终生效 |

关键点：**服务端在执行层再校验一次**。模型即使"幻想"出一个未开启的工具调用，也会被拒绝。

## PPT 大纲 + 每页表述稿

---

### 第 1 页 — 封面

**标题**: SimpleFileManager — 你的私人 AI 数据管家

**副标题**: 本地 NAS × 20B 模型 × 隐私优先，不连云的 Agent 文件管理

**口述**:
> "大家好，今天介绍的是一个跑在 Orange Pi 上的家庭 NAS 文件管理器。你的数据永远在你的硬盘上，AI 模型也是本地的 20B 参数模型，但 Agent 能力让你可以像聊天一样管理文件。"

---

### 第 2 页 — 问题

**标题**: 公有云方案的三大痛点

| 问题 | 说明 |
|------|------|
| 隐私 | 文件上传到云端，受制于服务商政策 |
| 成本 | iCloud/Google Drive 月订阅，长期昂贵 |
| 功能固定 | 厂商给什么用什么，不能自定义 |

**口述**:
> "现在大家存文件要么用 iCloud 要么用 Google Drive。但你的家庭照片、合同、孩子的作业——这些隐私数据要上传到别人的服务器。而且每月都要付费。更重要的是，你没法教它'帮我按日期整理照片'。"

---

### 第 3 页 — 解决方案

**标题**: 本地 NAS + 本地 AI = 数据主权 + 可定制

| 维度 | 公有云 | SimpleFileManager |
|------|--------|-------------------|
| 数据位置 | 云端服务器 | **你的硬盘** |
| 运行成本 | ¥50-200/月 | **一次硬件投入** |
| 隐私 | 服务商可访问 | **零出境** |
| 功能 | 固定 | **可定制 Agent 技能** |
| AI 能力 | 需联网 API | **本地 20B 模型** |

**口述**:
> "我们把 NAS 和 AI 模型都放在家里这台小机器上。所有文件分析、搜索、整理全部在本地完成。没有月费，数据不出你家门。"

---

### 第 4 页 — 产品演示

**标题**: 用自然语言管理文件，但危险动作必须你点头

**录屏**: 5 个场景

1. 语义搜文档（搜"押一付三"找到合同）
2. 散落文件整理 → 计划审批 → 批准执行
3. 模型想直接删除 → 服务端拒绝 → 改为提交计划
4. 上传技能包 → 沙箱里跑脚本
5. 重复文件识别 → 进回收站

**口述**:
> "你不需要记住文件名，只要记得内容就能找到。整理文件时，模型不会直接动手，而是提交一份计划让你批准。哪怕它想直接删除，服务端也会拦下来。你还可以上传自己的技能包——带方法论、带资源、带脚本，脚本在沙箱里跑，碰不到你的密钥和网络。"

---

### 第 5 页 — 技术架构

**标题**: Skills 系统 — 方法论 × 工具的分离，可见 × 可执行的分离

**图示**: 控制模型表格

**口述**:
> "技术上有两个核心设计。第一，技能是方法论，工具是原子能力，模型自己决定怎么组合。第二，'模型能不能看到'和'能不能直接调用'是两个独立的开关——危险工具默认只看不动，任何变更必须走计划审批。服务端在执行层还会再校验一次，不靠模型自律。"

---

### 第 6 页 — 安全设计

**标题**: 危险能力有边界，而不是靠承诺

| 工具 | 风险 | 默认 |
|------|------|------|
| search_files / list_directory / read_file | 安全 | 直接执行 |
| write_file / create_directory | 一般 | 直接执行 |
| move_file / delete_file | 谨慎 / **危险** | **仅计划执行** |
| run_command（沙箱） | **危险** | **关闭，仅计划执行** |

**沙箱边界**: 只读根文件系统 · 仅存储目录可写 · 禁网 · 清空环境变量 · 隐藏数据库与密钥 · 超时 + 输出上限

**口述**:
> "安全上我们做了三层。第一，工具有风险分级，危险工具默认只能写进计划。第二，任何文件变更都要人工批准，审批中心能看到每一项操作的完整路径。第三，命令执行跑在 bwrap 沙箱里——禁网、只读根文件系统、看不到你的 API key 和数据库。模型再怎么被诱导，也出不去。"

---

### 第 7 页 — 商业价值

**标题**: 不只是家庭工具，是小企业的合规基础设施

**三个市场**:

1. **家庭用户**: 照片档案、家庭财务、孩子成长记录 — 情感价值高，隐私敏感
2. **自由职业者 / 小工作室**: 合同管理、项目文档、作品归档 — 替代月订阅网盘
3. **隐私敏感行业**: 律师、心理咨询师、财务顾问 — 行业合规要求数据不出本地

**口述**:
> "家庭用户是最直接的——谁都不想把自己的照片上传到云端。但更大的市场是小企业和自由职业者。律师和心理咨询师有合规要求，客户资料不能上云。这套方案就是为这些人设计的。"

---

### 第 8 页 — 总结

**标题**: 你的数据，你的 AI，不连云

**三句话**:
- 数据主权 — 文件永远在你的硬盘
- 可定制 — 技能系统让 Agent 按你的方式工作
- 隐私优先 — 本地 20B 模型，零数据出境，危险能力有沙箱

**口述**:
> "总结一下：这是一个跑在 200 美元硬件上的私有 AI 文件管理器。你的数据在你家里，AI 按你的方式工作，危险动作有边界，不需要任何月费。谢谢大家。"
