# ZooGuide - 个性化动物园游览规划助手

## 一、项目背景与痛点

大型动物园（如南京红山森林动物园，占地 0.68 km²，23个场馆）游览时，游客常面临三大难题：

- **路线规划难**：不知道哪些场馆值得看、如何安排路线不走回头路
- **信息获取难**：动物园动辄 2-4 小时游览时间，体力分配、遮阳避雨都是现实问题
- **个性化难**：现有导览方案千人一面，无法满足带娃、情侣、老人等不同群体的差异化需求

ZooGuide 正是为解决这些问题而设计。

---

## 二、典型用户场景

| 场景 | 用户需求 | ZooGuide 解决方案 |
|-----|---------|-----------------|
| **带娃溜娃** | 3小时、孩子体力有限、喜欢考拉和大熊猫 | 推荐亲子路线，自动穿插休息点，讲解词童趣化 |
| **情侣打卡** | 4小时、喜欢拍照、不想走回头路 | 精选出片点位，拍照点评 + 徽章成就 |
| **陪老人游览** | 6小时、需爬山但不能太累 | 省力优先路线，自动过滤爬山路段，讲解词偏历史故事 |
| **研学探索** | 8小时、想深入了解动物知识 | 深度科普路线，覆盖稀有物种，讲解词专业化 |

## 三、产品简介

ZooGuide 是基于 AI 的个性化动物园游览规划助手，为**南京红山森林动物园**定制开发。

产品通过分析游客的个人偏好，生成定制化游览路线，支持游中动态调整、GPS 打卡、照片点评等交互功能。

**核心价值**："让每位游客按自己的方式逛出趟只属于自己的红山。"

> 红山森林动物园：中国第一个取消动物表演的动物园（2011年），中国唯一自收自支的公益性动物园，国内唯一能同时看到大熊猫、考拉、大猩猩的城市动物园。

## 四、核心功能

### 1. 个性化路线规划

**输入项**：时间预算（0.5h~12h）、同行类型、体力等级、防晒需求、爬山意愿、动物兴趣、入园门

**输出内容**：时间表、场馆路线、步行距离估算、休息点建议、个性化讲解词

**三种风格**：

| 风格 | 特点 |
|-----|------|
| 必看精选 | 推荐最受欢迎、最具代表性的场馆 |
| 小众探索 | 避开人流，发现隐藏亮点 |
| 平衡推荐 | 兼顾热门与特色 |

### 2. 游中动态调整

游览过程中可随时用自然语言调整："孩子累了想休息"、"太晒了想找室内"，系统自动重新规划后半段路线。

### 3. GPS 打卡定位

实时获取游客位置，自动计算到最近场馆的距离，支持到店打卡积累成就。

### 4. 拍照点评（合照彩蛋）

上传与动物的合照，AI 识别照片中的动物，生成出片评分 + 趣味评价 + 红山专属徽章。

### 5. AI 聊天助手

游客可通过自然语言咨询场馆信息、动物科普、路线调整建议、动物园历史和故事。

## 五、产品亮点

### 1. 全配置化设计（核心亮点）

换动物园只需修改配置文件，**前后端代码零修改**：

- `venues.json` - 场馆数据（坐标、动物、开放时间等）
- `system.json` - Agent 身份、对话规则、趣味梗
- `downloads/` - 下载资源

这是项目可复用于其他动物园的核心优势，具备商业化推广能力。

### 2. LLM 非必选（降级能力）

- 不配置 LLM 时，规则引擎提供完整基础功能
- 路线生成 < 1 秒（可演示"极速模式"）
- LLM 失败时自动回退到规则引擎，保证可用性

### 3. 叙事化讲解（差异化体验）

同一只长臂猿，不同人群听到不同版本：

| 人群 | 讲解风格 |
|-----|---------|
| 年轻人 | "身手敏捷的社牛" |
| 带娃家长 | "两岸猿声啼不住的主角" |
| 科普爱好者 | 分类学、保护级别 |
| 老年游客 | 历史典故、本土回忆 |

### 4. 红山专属梗库

| 梗 | 对应动物/场馆 |
|---|--------------|
| 野菜F4 | 大猩猩食材（香椿头、马兰头、小蒜头、枸杞头） |
| 站岗小哨兵 | 细尾獴 |
| 撞脸不撞DNA | 小熊猫 vs 大熊猫 |

### 5. 严格开闭馆过滤

支持「严格开闭馆」模式，自动排除已闭馆场馆（如周一二闭馆的场馆）。

## 六、技术方案特色

### 1. 规则引擎 + LLM 双路径架构

| 功能 | 规则引擎 | LLM 增强 |
|-----|---------|---------|
| 路线规划 | 候选场馆筛选（< 1s） | 路线编排 + 个性化讲解 |
| 聊天 | Regex 快路径（10+ 意图） | 自然语言理解 + 多轮对话 |
| 照片点评 | 红山梗库 + 徽章规则 | 多模态动物识别 |

### 2. 步行距离计算

1. 优先使用预计算的 OpenStreetMap 路径网络矩阵
2. 回退方案：Haversine 距离 × 1.5 路径倍数（山地地形修正）

### 3. 技术栈

| 层级 | 技术 |
|-----|------|
| 后端 | FastAPI + Pydantic + SQLite |
| LLM | OpenAI SDK（支持 OpenAI 兼容接口） |
| 前端 | React 18 + Vite + TypeScript + PWA |
| 认证 | bcrypt + UUID token |

### 4. API 接口（28个端点）

`/api/plan`（路线规划）、`/api/replan`（动态调整）、`/api/venues`（场馆信息）、`/api/chat`（Agent 对话）、`/api/checkin`（打卡）、`/api/photo`（照片点评）、`/api/facilities`（设施查询）、`/api/auth`（登录认证）

- glm-5 不支持图片识别，照片点评走规则引擎兜底
- 步行时间/场馆坐标为估算值，未实地测量
- 不接实时天气数据
- 不做支付/购票功能
