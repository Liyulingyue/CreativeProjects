# ZooGuide（Zoo陪逛）- 产品说明文档

## 一、产品简介

**ZooGuide** 是基于 AI 的个性化动物园游览规划助手，为**南京红山森林动物园**定制开发。

产品通过分析游客的个人偏好（时间、体力、同行人员、动物兴趣等），生成定制化的游园路线，并提供游中动态调整、动物打卡、照片点评等交互功能。

**核心价值**："让每位游客按自己的方式逛出趟只属于自己的红山。"

### 关于红山森林动物园

- 中国第一个取消动物表演的动物园（2011年）
- 中国唯一自收自支的公益性动物园
- 国内唯一能同时看到大熊猫、考拉、大猩猩的城市动物园
- 山地型城市森林动物园，占地 0.68 km²

## 二、核心功能

### 1. 个性化路线规划

根据用户输入生成定制化游览方案：

| 输入项 | 选项示例 |
|-------|---------|
| 时间预算 | 0.5h / 1h / 2h / 3h / 4h / 6h / 8h / 12h |
| 同行类型 | 情侣 / 溜娃 / 朋友 / 独自 / 研学 / 老人 |
| 体力等级 | 1-5（1=省力优先，5=深度探索） |
| 防晒需求 | 1-5（1=必须遮阳，5=无所谓） |
| 爬山意愿 | 是 / 否 |
| 动物兴趣 | 大熊猫 / 考拉 / 亚洲象 / 长臂猿 / 细尾獴 / ... |
| 入园门 | 北门 / 南门 / 东门 |

**输出内容**：时间表、场馆路线、步行距离估算、休息点建议、个性化讲解词

### 2. 三种路线风格

| 风格 | 特点 |
|-----|------|
| 必看精选 | 推荐最受欢迎、最具代表性的场馆 |
| 小众探索 | 避开人流，发现隐藏亮点 |
| 平衡推荐 | 兼顾热门与特色 |

### 3. 游中动态调整

游览过程中可随时调整计划：
- 自然语言反馈："孩子累了想休息"、"太晒了想找室内"
- 系统自动重新规划后半段路线
- 动态更新步行距离和时间

### 4. GPS 打卡定位

- 实时获取游客位置
- 自动计算到最近场馆的距离
- 支持到店打卡，积累成就

### 5. 拍照点评（合照彩蛋）

- 上传与动物的合照
- AI 识别照片中的动物
- 生成出片评分 + 趣味评价
- 解锁红山专属徽章

### 6. AI 聊天助手

游客可通过自然语言咨询：
- 场馆信息、动物科普
- 路线调整建议
- 动物园历史和故事

## 三、产品亮点

### 1. 全配置化设计（核心亮点）

换动物园只需修改配置文件，**前后端代码零修改**：

- `venues.json` - 场馆数据（23个场馆的坐标、动物、开放时间等）
- `system.json` - Agent 身份、对话规则、趣味梗
- `downloads/` - 下载资源

这是项目可复用于其他动物园的核心优势。

### 2. LLM 非必选（降级能力）

- 不配置 LLM 时，规则引擎提供完整基础功能
- 可演示"极速模式"（< 1 秒出方案）
- LLM 失败时自动回退到规则引擎，保证可用性

### 3. 叙事化讲解（差异化体验）

同一只长臂猿，不同人群听到不同版本：

| 人群 | 讲解风格 |
|-----|---------|
| 年轻人 | "身手敏捷的社牛" |
| 带娃家长 | "两岸猿声啼不住的主角" |
| 科普爱好者 | 分类学、保护级别 |
| 老年游客 | 历史典故、本土回忆 |

### 4. 红山专属梗库

| 梗 | 对应动物/场馆 |
|---|--------------|
| 野菜F4 | 大猩猩食材（香椿头、马兰头、小蒜头、枸杞头） |
| 站岗小哨兵 | 细尾獴 |
| 撞脸不撞DNA | 小熊猫 vs 大熊猫 |

### 5. 严格开闭馆过滤

支持「严格开闭馆」模式，自动排除已闭馆场馆（如周一二闭馆的场馆）。

### 6. 完善的成就体系

| 成就 | 条件 |
|-----|------|
| 拍照新手 | 拍 1 张照片 |
| 拍照入门 | 累计 5 张照片 |
| 拍照达人 | 累计 20 张照片 |
| 出片认证 | 照片评分 ≥ 90 |

## 四、技术方案特色

### 1. 规则引擎 + LLM 双路径架构

| 功能 | 规则引擎 | LLM 增强 |
|-----|---------|---------|
| 路线规划 | 候选场馆筛选（< 1s） | 路线编排 + 个性化讲解 |
| 聊天 | Regex 快路径（10+ 意图） | 自然语言理解 + 多轮对话 |
| 照片点评 | 红山梗库 + 徽章规则 | 多模态动物识别 |

### 2. 步行距离计算

1. 优先使用预计算的 OpenStreetMap 路径网络矩阵
2. 回退方案：Haversine 距离 × 1.5 路径倍数（山地地形修正）

### 3. 后端技术栈

- **框架**：FastAPI + Pydantic
- **Python**：3.12+
- **LLM**：OpenAI SDK（支持 OpenAI 兼容接口）
- **数据库**：SQLite
- **认证**：bcrypt + UUID token

### 4. 前端技术栈

- **框架**：React 18 + Vite + TypeScript
- **路由**：React Router v6
- **PWA**：可添加到主屏幕
- **样式**：原生 CSS + CSS 变量

### 5. API 接口（28个端点）

主要模块：

| 模块 | 说明 |
|-----|------|
| `/api/plan` | 路线规划 |
| `/api/replan` | 动态调整 |
| `/api/venues` | 场馆信息 |
| `/api/chat` | Agent 对话 |
| `/api/checkin` | 打卡 |
| `/api/photo` | 照片点评 |
| `/api/facilities` | 设施查询 |
| `/api/auth` | 登录认证 |

### 6. 数据结构

核心配置文件：

```
Backend/data/
├── venues.json      # 23个场馆完整数据（唯一真相源）
├── system.json      # Agent身份 + 规则 + 梗
├── quiz_options.json # 问卷选项配置
└── facilities.json  # 设施数据（厕所、餐饮、充电宝等）
```

## 八、已知限制

- glm-5 不支持图片识别，照片点评走规则引擎兜底
- 步行时间/场馆坐标为估算值，未实地测量
- 2025年10月开放的南门新区信息可能持续更新
- 不接实时天气数据
- 不做支付/购票功能
